# Listing photos and compact type badges

Home and Browse use the selected top-center photo by label, with a fallback
to another listing photo only when the top-center image is unavailable.
The complete card fits inside its thumbnail. A small type badge appears above
the asking price on the right; listing detail uses the same price/badge group.
Pokemon retains its type symbol. New Magic scans record mana colors, including
multicolor, using generic symbols. Existing Magic listings fall back to their
recorded card type when no mana colors are available. No automatic rescans run.
Deploy backend 2.18.4 before Android 0.21.4; keep google-services.json and
local.properties. All previous camera, model-selector and tracking changes remain.
